# Your Week in One Line

One line summing up the week: a token-radar bounty scored 0.9073
against a paid line of 0.9621 — 5.5 points short, and the week
invoices the miss as experience.

## Entry

> Radar 0.9073, paid line 0.9621: 5.5 points short, and the week invoices it as experience.

89 characters — inside the competition's 1–100 character gate.

## How it works

`main.py` (Python standard library only, no network) writes that
exact line to `/output/entry.txt`, with no trailing newline.

## Run

```sh
python3 main.py
```
